# SOC Cybersecurity Labs

This repository documents my hands-on learning journey focused on
Security Operations Center (SOC) fundamentals and blue team practices.

## Objectives
- Develop strong network traffic analysis skills
- Practice threat detection and investigation techniques
- Build a SOC-oriented cybersecurity mindset
- Document learning in a structured and professional way

## Lab Environment
- Attacker Machine: Kali Linux
- Target Machine: Metasploitable
- Network: Isolated virtual lab (Host-only)

## Tools & Technologies
- Wireshark
- tcpdump
- Linux networking utilities
- VirtualBox

## Structure
- `environment-setup/` – Lab and network configuration
- `wireshark/` – Packet analysis notes and filters
- `tcpdump/` – Packet capture techniques
- `labs/` – SOC-style lab writeups
- `notes/` – Blue team and SOC theory notes

## Disclaimer
All activities are performed in a controlled lab environment for educational purposes only.
